# INHACK 인코그니토 프로젝트/ AINHA-정시훈, 목진서, 김준서, 구주원
## 본 프로젝트는 AI캐릭터 챗봇 취약점 분석 프로젝트를 위한 AI기반 캐릭터 챗봇 시뮬레이터이다.

## 🔍 프로젝트 핵심 성과

> 상용 캐릭터 AI 채팅의 주요 흐름을 재현한 로컬 시뮬레이터에서 LLM 보안 위협을 화이트박스 방식으로 검증하고, 취약점의 발생 경로와 코드 수준 대응 방안을 도출한 프로젝트입니다.

### 1. 분석 대상과 위협 모델

- **분석 대상:** 사용자 입력 → LLM 응답 → 장기기억 추출 → JSON·SQLite 저장 → 다음 대화 프롬프트 반영으로 이어지는 캐릭터 AI 채팅 구조
- **대상 모델:** Gemini 2.5 Flash, GPT-4o-mini
- **검증 방식:** Playwright 기반 브라우저 자동화와 Python 화이트박스 직접 호출을 결합
- **점검 범위:** 직접·간접 프롬프트 인젝션, 탈옥, 장기기억 오염, Crescendo 멀티턴 공격, 토큰 분할, 프롬프트 유출 등 11개 분류·30여 개 공격 기법
- **판정 근거:** 모델 응답뿐 아니라 SQLite 저장값과 트래킹 서버 로그를 함께 확인

### 2. 발견한 취약점

| 발견 사항             | 발생 경로 및 영향                                                                          | 프로젝트 내 심각도 |
| ----------------- | ----------------------------------------------------------------------------------- | ---------- |
| **장기기억 메모리 인젝션**  | 사용자 입력이 별도 검증 없이 메모리 추출 프롬프트에 포함되고, 생성된 JSON이 DB에 저장된 뒤 다음 대화의 시스템 프롬프트에 반영됨        | Critical   |
| **비밀번호 평문 저장**    | 사용자 비밀번호가 해시 처리 없이 SQLite에 저장되어 DB 노출 시 계정정보가 그대로 유출될 수 있음                          | Critical   |
| **모델별 방어 결과 불일치** | 동일한 방어 프롬프트에서도 Gemini 2.5 Flash와 GPT-4o-mini의 공격 차단 결과가 달라 모델 지침만으로 일관된 통제가 어려움을 확인 | 주요 관찰 결과   |

메모리 인젝션은 준비한 4개 기법에서 모두 악성 메모리 생성을 확인했습니다. 이를 통해 단일 응답을 우회하는 공격뿐 아니라, 공격자의 지시가 장기기억을 거쳐 이후 대화에 영향을 주는 **지속형·멀티턴 공격 경로**를 검증했습니다.

### 3. 재현 방법과 대응 방안

#### 메모리 인젝션 재현

1. 로컬 시뮬레이터에서 메모리 생성을 유도하는 입력을 전송합니다.
2. 메모리 추출 결과와 SQLite `long_term_memory` 저장값을 확인합니다.
3. 새 대화를 시작한 뒤 저장된 내용이 다음 응답의 프롬프트에 반영되는지 확인합니다.
4. 동일한 입력을 두 모델에 적용해 공격 성공 여부를 비교합니다.

#### 대응 방안

- 메모리 추출 전 사용자 입력 검증 및 정제
- LLM이 생성한 메모리에 대한 JSON 스키마·필드 검증
- 데이터와 시스템 지시문을 분리하는 프롬프트 구조 적용
- 단일 입력이 아닌 대화 전체의 누적 위험도를 평가
- 비밀번호 저장 시 bcrypt 또는 Argon2 기반 해싱 적용
- 모델의 방어 응답에만 의존하지 않고 코드 단계 검증을 병행

> 구체적인 실험 결과와 공격별 판정 근거는 [분석 보고서](https://github.com/katarinabluu-gosegulover/AI-CHAT-SIMULATOR/blob/main/AINHA%20%E1%84%87%E1%85%A9%E1%84%80%E1%85%A9%E1%84%89%E1%85%A5.pdf)에서 확인할 수 있습니다.

### 4. 김준서 담당 범위 및 발표

- Python·Streamlit 기반 시뮬레이터 개발 참여
- 사용자별 `user_note` 저장 항목과 해당 내용을 AI 응답에 반영하는 처리 흐름 추가
- Playwright 자동화와 Python 직접 호출을 결합한 공격 검증
- 장기기억 생성·DB 저장·다음 대화 반영 경로 분석
- 공격 유형, 위험도, 성공 여부 및 권장 대응 방안 결과표 작성
- 전국 대학 보안동아리 연합 **인코그니토 컨퍼런스**에서 연구 결과 발표(팀원이 발표함)
